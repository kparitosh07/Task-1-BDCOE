# Movie Finder

## About

Movie Search App The Movie Search App is a web page built using HTML, CSS, and JavaScript that allows users to search for movies and view relevant movie information through an external API(OMDb API). The project focuses on working with JavaScript Fetch API, Promises, async/await, error handling, and API error handeling.
